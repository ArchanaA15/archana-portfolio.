# Archana A – Portfolio
Setup: `npm install` then `npm run dev` (http://localhost:5173). Build: `npm run build` (output in `dist/`), preview with `npm run preview`.
Edit content in `src/data.js`. To show a GitHub button, set `github` to a real repo URL on a project.
Resume: replace `public/resume/Archana_Resume.pdf`. Uses HashRouter, so `dist/` works on any static host.
